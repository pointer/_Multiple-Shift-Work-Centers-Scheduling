# Backend Application

This is the backend part of the fullstack application built using Python and Flask.

## Project Structure

- `src/app.py`: Entry point of the backend application.
- `src/routes/__init__.py`: Defines and registers the routes for the application.
- `src/models/__init__.py`: Contains the data models used in the application.

## Installation

To install the required dependencies, run:

```
pip install -r requirements.txt
```

## Running the Application

To run the backend application, execute:

```
python src/app.py
```
